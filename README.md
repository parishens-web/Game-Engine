# ร้านอร่อยไอเดิล 🍳

เกม idle เปิดร้านอาหารบนเว็บ (แนว Eatventure) เขียนด้วย HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งอะไร

## วิธีเล่น

เปิด `index.html` ในเบราว์เซอร์ได้เลย (เล่นบนมือถือได้)

- ลูกค้าจะเดินเข้ามาต่อคิวที่แต่ละเมนู ให้**แตะจาน**เพื่อทำอาหารแล้วรับเงิน
- **อัปเลเวล**เมนูเพื่อเพิ่มรายได้ พอถึง Lv 10, 25, 50, 100... รายได้จะ x2
- **จ้างผู้จัดการ**แล้วเมนูนั้นจะทำอาหารเองอัตโนมัติ และยังได้เงินตอนปิดเกมด้วย (สูงสุด 2 ชั่วโมง)
- แท็บ**อัปเกรด**: ลูกค้ามาถี่ขึ้น, ทำอาหารเร็วขึ้น, รายได้ x1.5, เพิ่มที่นั่ง
- แท็บ**สาขา**: เมื่อหาเงินได้ 10M ขึ้นไป เปิดสาขาใหม่เพื่อรับ ⭐ (ดาวละ +10% รายได้ถาวร)

เกมจะเซฟเองอัตโนมัติในเบราว์เซอร์ทุก 5 วินาที

## ปรับแต่งเกม

ค่าบาลานซ์ทั้งหมดอยู่ด้านบนของ `game.js`:

- `DISHES`: เมนูอาหาร (ชื่อ, อีโมจิ, ราคาปลดล็อก, รายได้, เวลาทำ) เพิ่มเมนูใหม่ได้ด้วยการเพิ่มแถว
- `UPGRADES`: อัปเกรดร้าน
- `COST_GROWTH`, `MILESTONES`, `BASE_ARRIVAL`, `PRESTIGE_REQ` ฯลฯ: ค่าตัวคูณต่าง ๆ

## เปิดเล่นบนมือถือผ่าน GitHub Pages
